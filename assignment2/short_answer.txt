A1. some tradeoffs between a set and unordered_set is that set uses a red-black tree internally to store elements, while unordered_set uses a hashtable; so set can be faster. another hash function is the SHA-1 function.

/*
An std::set is an ordered container implemented as a balanced binary search tree (typically a red-black tree), which keeps elements in sorted order and supports logarithmic-time operations. In contrast, an std::unordered_set uses a hash table for storage, which allows for average-case constant-time insertions, deletions, and lookups, but does not maintain any order. The tradeoff is between ordering and performance: use set when order matters, and unordered_set when speed is more important and ordering is irrelevant.
*/
